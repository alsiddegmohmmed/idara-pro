---
description: Record an architecture decision as a new ADR
argument-hint: <decision to record>
---

Write a new ADR for: $ARGUMENTS

1. Look in `docs/adr/` for the highest number and use the next one (4 digits).
2. Use `docs/adr/0000-template.md`. Status: Proposed (unless the owner said it is decided).
3. Give at least two real options with trade-offs (complexity, cost, scalability, fit for a one-person team).
4. If it changes an earlier ADR, mark the old one "Superseded by ADR-XXXX".
5. Update docs/architecture/overview.md if the decision changes it.
